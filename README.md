# رحلة العراق

لعبة منصات جانبية لويندوز 64-بت. تضم ١٩ محافظة و١٥٢ مرحلة، مع ٢٠ شخصية وحفظ مستقل لكل واحدة.

## التحكم

| الزر | الحركة |
| --- | --- |
| الأسهم أو A وD | المشي |
| Space أو W | القفز |
| X | الضربة |
| J | أداة المحافظة |
| E | المصابيح في حلبجة |
| M | كتم الموسيقى أو تشغيلها |
| Esc | الوقفة |
| F1 | عن اللعبة |

الحفظ تلقائي عند الرايات وبوابات المراحل. تبدأ كل شخصية جديدة من بغداد. تقدم الشخصيات محفوظ ضمن مجلد المستخدم.

## البناء والفحص

يتطلب بناء المشروع ويندوز و.NET 8 SDK. يتطلب إنشاء ملف التنصيب Inno Setup 6.

```powershell
dotnet build .\IraqPlatformer.csproj
.\BuildInstaller.ps1 -Compiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

ينتج السكربت `dist/IraqPlatformer-Setup.exe` بعد اجتياز فحوص الحملة. مسار GitHub Actions يدوي ويفحص تثبيت الملف وتشغيل الفحوص منه وإزالته قبل إنشاء الإصدار.
